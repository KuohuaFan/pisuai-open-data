What this project delivers

不是資料堆積，
而是可以逐筆追問的來源庫。

全國資料目錄提供廣度，人工治理來源提供判讀深度。兩者分層保存，避免把「已收錄」誤認為「可無限制使用」。

從官方目錄到公共敘事，
每一步都有紀錄。

Rights before reuse

程式碼開源，
不等於上游資料自動開放。

每個治理來源都帶有權利分級。涉及裁判、醫療、政治獻金、公司關係、不動產交易及行政裁罰時，平台採更保守的索引與導流政策。

A可公開再利用保留來源與顯名
B僅索引與導流不鏡像原始內容
C限內部使用不進入公開層
D另取授權權利確認後再用
M逐欄審查混合權利與敏感欄位

「收錄 metadata 不表示每筆原始資料都已完成法律審查；實際使用仍應核對官方最新版本、授權、個資與第三人權利。」
